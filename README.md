## Sobre mim

Meu nome é **José Gabriel da Rocha Coutinho** e sou estudante do curso técnico integrado em Informática no IFRN.

Tenho interesse em programação, desenvolvimento de software e tecnologias que ajudam a resolver problemas reais. Venho construindo minha base técnica por meio dos estudos e de projetos próprios, explorando tanto o desenvolvimento web quanto a programação.

Meu objetivo é evoluir como desenvolvedor, aprender boas práticas e criar projetos que tenham utilidade para outras pessoas.

Acredito que aprender envolve mais do que fazer algo funcionar: também é importante entender como funciona, reconhecer limitações e buscar formas de melhorar.
